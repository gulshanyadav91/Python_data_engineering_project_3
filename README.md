# 📊 <span style="color:#2196F3">Python Data Analysis Project</span>

🟢 A Python project that combines **API data, web scraping, JSON processing, and data analysis** using Pandas.

---

## 🟢 Features

* 👥 **User Analysis:** Total users, unique companies and top 5 companies.
* 📚 **Book Analysis:** Average price, highest-rated books and rating counts.
* 💰 **Price Analysis:** Maximum, minimum and average book prices.
* 📄 **JSON Reports:** Saves the complete analysis in `report.json`.

---

## 🟣 Technologies Used

* 🐍 Python
* 🐼 Pandas
* 🌐 Requests
* 🍲 BeautifulSoup
* 📋 JSON
